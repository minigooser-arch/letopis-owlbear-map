# Letopis Map Sync

Лёгкое Owlbear Rodeo-расширение для стратегической карты Minecraft-сервера «Летопись».

Нового ПО на Minecraft/VPS не требуется. GitHub Actions по расписанию скачивает публичные low-res PNG BlueMap с `https://map.letopisrp.ru`, собирает стратегические изображения и публикует их вместе с расширением на GitHub Pages. В Owlbear сами PNG остаются внешними URL-изображениями: расширение хранит только логику синхронизации и координат.

## Геометрия карты

- игровая граница: X `-5760..12639`, Z `-16720..-6961`;
- внутреннее представление границы: `[-5760,12640) × [-16720,-6960)`;
- 1 клетка Owlbear = `160×160` блоков = `10×10` чанков;
- `(0,-10000)` — верхний правый угол опорной клетки;
- текущая граница пересекает 18 выходных тайлов (6×3);
- каждый выходной тайл покрывает `4000×4000` блоков и публикуется как PNG `2000×2000`;
- для текущей границы GitHub скачивает 798 исходных low-res PNG BlueMap.

## Что делает расширение

- GM один раз привязывает `(0,-10000)` к нужному пересечению сетки Owlbear;
- GM синхронизирует 18 заблокированных `IMAGE` на слое `MAP`;
- при следующих успешных публикациях меняются URL существующих изображений, а не их игровая привязка;
- инструмент координат показывает `X`, `Z` и Minecraft-чанк под курсором;
- координаты или `/tp X ~ Z` можно скопировать;
- игроки не могут обновлять карту, но могут использовать инструмент координат.

## Автообновление

Workflow `.github/workflows/deploy-pages.yml` запускается:

- при push в `main`;
- вручную через `workflow_dispatch`;
- по расписанию — в 03:15 UTC каждого третьего дня месяца.

Сборка публикуется только после тестов exporter, тестов/сборки extension и проверки готового Pages-сайта. После deploy workflow дополнительно проверяет CORS на PNG, чтобы Owlbear мог использовать внешние изображения.

Подробная первичная установка: [`DEPLOY.md`](DEPLOY.md).
